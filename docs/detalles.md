# Detalles sobre las energías renovables

Este es el fichero secundario enlazado desde [markdown.md](../markdown.md).

## Ventajas

- Reducen las emisiones de gases de efecto invernadero.
- Disminuyen la dependencia de combustibles fósiles.
- Generan empleo local en instalación y mantenimiento.

## Retos

1. Intermitencia de la producción (sol y viento).
2. Necesidad de sistemas de almacenamiento.
3. Inversión inicial elevada.
